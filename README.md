# نشرة الموثوق — جامع أخبار عربي بنشرتين يوميًا

تطبيق ويب عربي (RTL) يجمع الأخبار من مصادر حقيقية، ويوحّد تغطيات الحدث الواحد، ويصدر نشرتين يوميًا في موعدين ثابتين: 7 صباحًا و7 مساءً بتوقيت الرياض، مع أرشيف قابل للبحث ولوحة إدارة.

- الخلفية: Node.js 22.13 أو أحدث، دون أطر عمل.
- قاعدة البيانات: SQLite المدمجة في Node، مع فهرس بحث FTS5.
- الاعتمادية الخارجية الوحيدة: حزمة `@anthropic-ai/sdk` للتلخيص الاختياري.

## ما يعمل الآن (وكيف تحققنا منه)

لا توجد بيئة Node على جهاز التطوير، ولم يُثبَّت عليه شيء بطلب المالك.

لذلك شُغّل الكود الحقيقي دون تعديل داخل متصفح، عبر محاكاة لوحدات Node وقاعدة SQLite مبنية بـ WebAssembly (مجلد `dev/harness`).

- **الاختبارات الآلية:** 19 اختبارًا في `test/` نجحت كلها، بمحرّك البحث FTS5 وبالمسار البديل دونه.
- **تشغيل على بيانات حقيقية** بتاريخ 2026-10-23، من نسخ محلية لخلاصات 25 مصدرًا مفعّلًا:
  - نجح الجلب من المصادر الـ25 كلها.
  - رُصد 2546 عنصرًا، منها 691 جديدًا ضمن نافذة الجلب.
  - استُبعد 153 عنصرًا رياضيًا أو منوعات.
  - نتج نحو 510 أحداث موحّدة، ودُمجت 26 تغطية.
- **الواجهة ولوحة الإدارة:** عوينتا بالبيانات نفسها على عرض الحاسوب والجوال، وبالوضع الليلي.

**غير مُتحقَّق بعد:** التشغيل على Node الحقيقي، والتشغيل الفعلي على GitHub Actions، والتلخيص الفعلي عبر Claude لعدم وجود مفتاح. التفاصيل في قسم «حدود التحقق».

## النشر المجاني على GitHub (الطريقة المعتمدة)

لا يحتاج أي برنامج على جهازك، ولا بطاقة دفع. كل شيء يحدث في سحابة GitHub:

- **GitHub Actions** يعمل كل ساعة. التحديث الفعلي لا يحدث إلا عندما تحين خانة الـ7 ساعات التالية، والساعات الأخرى تنتهي فورًا دون تغيير.
- **قاعدة البيانات** ملف مضغوط يُحفظ في إصدار باسم `db` داخل المستودع، ومعه النسخة السابقة للاسترجاع.
- **الموقع** صفحات ثابتة تُنشر على GitHub Pages، والبحث يعمل داخل المتصفح.
- **الاختبارات** تعمل تلقائيًا على Node حقيقي عند كل تعديل.

### خطواتك (مرة واحدة)

1. أنشئ حسابًا مجانيًا على GitHub.
2. أنشئ مستودعًا جديدًا **عامًا (Public)** دون ملف README. الاستضافة المجانية للصفحات والتشغيل غير المحدود يتطلبان أن يكون المستودع عامًا.
3. في صفحة المستودع الفارغ اختر «uploading an existing file»، واسحب **كل محتويات** مجلد «تطبيق ويب» بما فيها مجلد `.github`، ثم اضغط Commit.
4. من Settings ← Pages: اجعل Source على «GitHub Actions».
5. من Settings ← Actions ← General: اختر «Read and write permissions» واحفظ.
6. (اختياري) من Settings ← Secrets and variables ← Actions أضف السر `ANTHROPIC_API_KEY` لتفعيل التلخيص. ويمكنك إضافة المتغير `AI_MODEL` بقيمة `claude-haiku-5-5` للنموذج الأرخص.
7. من تبويب Actions اختر `update` ثم Run workflow. هذا أول تحديث، ويستغرق بضع دقائق.

بعد نجاحه يظهر الموقع على الرابط:

```
https://اسم-المستخدم.github.io/اسم-المستودع/
```

وتقرير الإدارة على الرابط نفسه مضافًا إليه `admin.html`.

**بعد ذلك:** تحقق من أن التحديث التالي حدث وحده بعد 7 ساعات (يظهر في تبويب Actions وفي تقرير الإدارة). عندها فقط يمكن القول إن الجدولة تعمل، ويمكنك حذف المجلد من جهازك.

### الإدارة في النسخة المجانية

لا توجد لوحة إدارة تفاعلية، لأن الموقع ثابت. الإدارة تتم بتعديل ملفات في المستودع من متصفح GitHub نفسه:

- **المصادر:** `src/sources.js`، تفعيلًا وتعطيلًا وإضافة.
- **تصحيح الدمج:** `config/overrides.json`:
  - `split`: فصل عنصر دُمج خطأ.
  - `merge`: دمج حدثين بالصيغة `[الإبقاء, المدمج]`.
  - `dismiss`: إغلاق مراجعة.
  - `hide` و`unhide`: إخفاء حدث وإظهاره.
- **تحديث يدوي:** Actions ← update ← Run workflow. التشغيلات لا تتزامن أبدًا؛ تنتظر بالدور.

أرقام العناصر والأحداث تظهر في تقرير الإدارة `admin.html`.

### حدود النسخة المجانية

- **المستودع عام:** الكود وملف قاعدة البيانات مرئيان للجميع. لا توجد فيهما أسرار؛ المفاتيح تبقى في Secrets.
- **التوقيت:** GitHub قد يؤخر التشغيل المجدول حتى ساعة أو أكثر وقت الضغط. الفاصل الثابت يُحسب من المرجع، والتأخير لا يغيّر مواعيد الخانات التالية.
- **الإيقاف بعد 60 يومًا:** GitHub يوقف الجداول في المستودعات الخاملة. يعيد سير العمل تفعيل نفسه في كل تشغيل؛ إذا وصلتك رسالة من GitHub بالإيقاف، فعّله من تبويب Actions.
- **حجم الموقع:** حد GitHub Pages هو 1 جيجابايت. ملفات النشرات تنمو تقريبًا 30 إلى 60 ميجابايت شهريًا، فقد يلزم بعد نحو سنة ضغط الأرشيف القديم.
- **صفحات الأحداث التفصيلية** تُنشر لآخر 120 يومًا. الأقدم يبقى في النشرات والبحث.

## التكلفة

- **GitHub (المستودع، Actions، Pages):** مجاني للمستودعات العامة.
- **التلخيص بالذكاء الاصطناعي (اختياري):** تقديري على 60 حدثًا كحد أقصى لكل تحديث، ونحو 103 تحديثات شهريًا:
  - `claude-opus-5-5` (الافتراضي): قرابة 100 دولار شهريًا.
  - `claude-haiku-5-5`: قرابة 3 دولارات شهريًا، بجودة أقل.
  - بدون مفتاح: صفر، والموقع في وضع محدود صريح.
- **بديل مدفوع للمستقبل:** Fly.io بقرابة 3.84 دولار شهريًا، مع لوحة إدارة تفاعلية. الإعداد جاهز في `Dockerfile` و`fly.toml`.

## التشغيل كخادم (بديل)

على أي جهاز أو خادم فيه Node 22.13 أو أحدث:

```bash
npm install
```

```bash
npm run start:local
```

انسخ `.env.example` إلى `.env` أولًا. الموقع على المنفذ 8080، ولوحة الإدارة التفاعلية على `/admin`.

### الجدولة: 7 صباحًا و7 مساءً (الوضعان)

- الموعدان مضبوطان في `.github/workflows/update.yml` عبر `SCHEDULE_ANCHOR` و`INTERVAL_HOURS: 12`. تغييرهما يعيد ضبط الجدول دون تشغيل خارج الموعد.
- يُعدّ الخبر «تحديثًا جوهريًا» فقط إذا تغيّر رقم فيه؛ التغطيات اللاحقة الأخرى تُلحق بالحدث دون أن يعود للظهور.

- المرجع الزمني يُحفظ في قاعدة البيانات عند أول تشغيل، أو من `SCHEDULE_ANCHOR`.
- الخانات: `المرجع + ك × 7 ساعات`. لا يعاد العد عند منتصف الليل.
- كل تشغيل يُسجَّل في جدولي `runs` و`schedule_slots` بالوقت المخطط والفعلي والنتيجة.
- قفل يمنع تشغيلين متزامنين. إعادة المحاولة عند الفشل: 2 ثم 10 ثم 30 دقيقة.
- بعد الانقطاع تُدمج الخانات الفائتة في تشغيل استدراكي واحد ونشرة واحدة.
### مصادر تحتاج اشتراكًا أو اتفاقية

- العربية: ترفض الطلبات الآلية.
- التكلفة غير معروفة، وتُطلب من المزوّد مباشرة.

## المصادر

القائمة الكاملة وحالة كل مصدر في `src/sources.js`، وفي صفحة «المصادر والتغطية» داخل الموقع.

**المفعّلة (20)، وكلها عربية:**

- رسمية: وكالة الأنباء السعودية (واس)، وأخبار الأمم المتحدة بالعربية (عام، الصحة، المناخ).
- صحف ومواقع إخبارية: عكاظ (محليات واقتصاد)، الشرق الأوسط، بي بي سي عربي، فرانس 24 (عام واقتصاد)، DW عربية (عام وعلوم)، سكاي نيوز عربية، CNN بالعربية، إندبندنت عربية، الجزيرة، يورونيوز عربي.
- اقتصاد: الشرق للأخبار الاقتصادية.
- تقنية: البوابة العربية للأخبار التقنية، عالم التقنية.

**أُوقفت المصادر الإنجليزية (14)** ليبقى الموقع عربيًا بالكامل دون الحاجة إلى ترجمة، ومنها الاحتياطي الفيدرالي ومنظمة الصحة العالمية وBBC وTechCrunch. ما زالت مسجّلة في `src/sources.js` ويمكن إعادة تفعيلها.

**معطّلة مع ذكر السبب:** الإحصاء، صندوق الاستثمارات العامة، المنصة الوطنية، العربية، أوبك، صندوق النقد.

أُزيل قسما سوق الأسهم وتحليل شركات تداول من الموقع، وأخبار السوق والشركات تُصنَّف ضمن «الاقتصاد السعودي».

**أقسام السعودية (14):** السياسة والقرارات الرسمية، المشاريع والتنمية، الاقتصاد السعودي، القوانين وحقوق المستهلك، المناخ والبيئة، التجارة وسلاسل الإمداد، العقار والمدن، التعليم والوظائف، السفر والطيران، الغذاء والزراعة، الثقافة والمجتمع، الأمن الرقمي والاحتيال، التحقق من الأخبار، الخدمات والمستجدات المحلية.

**أقسام العالم (6):** العالم والسياسة، الاقتصاد والأسواق، النفط والطاقة، التقنية والذكاء الاصطناعي، الشركات والأعمال، العلوم والصحة.

التصنيف يعتمد على قوائم كلمات لكل قسم في ``src/core/lexicon.js``، وعلى تصنيف المصدر نفسه عند توفره.

المصادر الجديدة تُضاف من لوحة الإدارة وتبدأ معطّلة. كل طلب جلب مقيد بالمضيفين المسموح بهم لذلك المصدر، بما في ذلك التحويلات.

## منع التكرار

التنفيذ في الخلفية وقاعدة البيانات، لا في الواجهة.

1. تنظيف الروابط من معاملات التتبع، وتوحيد `www/m/amp`، وتتبّع التحويلات. قيود تفرّد على `(source_id, guid)` و`url_key`.
2. بصمة للنص المطبّع: المقال نفسه إذا أعيد نشره يُربط بحدثه الأصلي، ولا يعود كخبر جديد.
3. العنصر الذي يصل متأخرًا عن نشره بأكثر من 72 ساعة يُؤرشف دون أن يظهر كجديد.
4. مطابقة الحدث تجمع عدة إشارات:
   - تشابه العنوان، بالحروف وبالكلمات.
   - تشابه النص، مع ترجيح الكلمات بحسب ندرتها (IDF).
   - الجهات المذكورة، والأرقام المشتركة، والزمن.
   - المقارنة تتم مع كل خبر داخل الحدث على حدة، حتى لا يتضخم الحدث فيجذب أخبارًا غير مرتبطة.
5. موانع الدمج:
   - شركتان مختلفتان، كنتائج بنكين في موسم واحد.
   - دولتان فاعلتان مختلفتان في العنوانين، كـ«مصر تدين» و«قطر تدين».
   - الشركة نفسها بموضوع مختلف.
6. التطور الجوهري، كرقم جديد للبند نفسه أو قرار جديد، يُحفظ تحديثًا مرتبطًا مع وصف ما تغيّر. أما المصدر الإضافي أو إعادة الصياغة فلا يعيدان نشر الخبر.
7. كل دمج يُحفظ مع سببه ودرجته. الحالات المشكوك فيها تبقى منفصلة وتذهب لقائمة مراجعة. الإدارة تتيح فصل دمج خاطئ ودمج حدثين فاتهما الدمج.

**القياس على بيانات حقيقية:** على عيّنة صنّفناها يدويًا، دُمجت 19 من 22 تغطية متطابقة، ولم يُدمج أي زوج من 7 أزواج مختلفة. وكل عمليات الدمج الـ26 في التشغيل الكامل كانت صحيحة بالمراجعة اليدوية.

العيّنة استُخدمت أيضًا للضبط، فهذه ليست نسبة دقة مضمونة. المطابقة الدلالية لا تبلغ 100%.

## حدود التحقق والتغطية

- **لم يُشغَّل على Node فعليًا.** الاختبارات شُغّلت بمحاكاة `node:sqlite` عبر sql.js. السلوك متطابق في واجهة الاستدعاء، لكن يجب تشغيل `npm test` على الخادم بعد النشر.
- **التلخيص العربي لم يُختبر مع Claude فعليًا** لعدم وجود مفتاح. اختُبر فقط التحقق من المخرجات: رفض الأرقام غير الموجودة في المصدر، وحذف الروابط، والتراجع إلى الوضع المحدود عند الفشل.
- **في الوضع المحدود:**
  - عناوين المصادر الإنجليزية تُعرض بلغتها.
  - الملخص مقتطف قصير (حتى 220 حرفًا) موسوم بأنه من المصدر.
  - لا يُعرض «لماذا يهم؟».
  - المطابقة بين خبر عربي وآخر إنجليزي عن الحدث نفسه لا تتم إلا بعد التلخيص العربي.
- **الأعداد الصغيرة المكتوبة بالكلمات** (مثل «ارتفاع الوفيات إلى اثنين») لا تُكتشف تطورًا جوهريًا آليًا، فقد تظهر كحدث مستقل. وضع الذكاء الاصطناعي والمراجعة اليدوية يعالجانها.
- **ردود فعل حدث واحد** (إدانات من دول متعددة) تبقى أحداثًا منفصلة عمدًا.
- **الاستدراك بعد انقطاع طويل** محدود بما تحتفظ به الخلاصات (عادة آخر 20 إلى 100 عنصر).

## هيكل المشروع

- `src/core/`: منطق نقي (تطبيع عربي، روابط، تحليل الخلاصات، تصنيف، منع تكرار، جدولة، تحليل مالي).
- `src/`: قاعدة البيانات، الجلب، خط المعالجة، النشرات، البحث، المجدول، الخادم.
- `migrations/`: ترحيلات قاعدة البيانات.
- `public/`: الواجهة ولوحة الإدارة.
- `test/`: اختبارات `node:test`.
- `src/cli.js` و`src/static/`: وضع GitHub (التحديث وبناء الموقع الثابت).
- `config/`: ملفات الإدارة في الوضع المجاني.
- `.github/workflows/`: التحديث والنشر، والاختبارات.
- `dev/`: أدوات تطوير فقط (خادم ملفات PowerShell، ومشغّل اختبارات داخل المتصفح). لا تُنشر.
